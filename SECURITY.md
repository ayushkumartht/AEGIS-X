# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | Yes       |
| < 0.2   | No        |

## Reporting a Vulnerability

Do NOT open a public issue. Email maintainers with:
1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact

We respond within 48 hours and patch within 7 days.
